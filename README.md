# Hybrid Work Task Management System

## Next.js (App Router)
```
npm install
npm run dev      # http://localhost:3000
npm run build && npm start
```
Routes: `/` (login), then `/dashboard`, `/supdash`, `/tasks`, `/taskdetail`, `/accomplish`,
`/performance`, `/evaluate`, `/users`, `/taskcreate`, `/notif`, `/reports`, `/flow`, `/profile`.
Pick Employee or Supervisor on the login screen; the role is kept in sessionStorage.

## Plain HTML / CSS / JS
Open `standalone/index.html` (uses `styles.css` and `app.js` beside it). No install needed.
